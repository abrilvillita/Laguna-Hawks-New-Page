# Laguna HAWKS · New Page

A newer website concept for Laguna HAWKS, a student engineering team in Torreón, Coahuila. The repository contains a public landing page and a separate team hub prototype.

## What's here

- `index.html` — Spanish-language public site for the team, vehicle, results and sponsor information.
- `panel.html` — team hub interface with sign-in and project items.
- `supabase-schema.sql` — schema used by the team hub prototype.
- `laguna-hawks-logo.png` — team artwork.

## Status

Work in progress. Review team-approved information before using this version as the official site. The hub requires its own Supabase configuration and access controls; do not place private keys in this repository.

## Preview

Open `index.html` locally in a browser. The public page is static. The team hub is a separate prototype and requires backend setup.
